# Service Connection Platform

**Where skills meet opportunity.**

This is an India-focused service-connection platform connecting clients with independent/local service providers.

## Development Phase
This project is currently in the **FRONTEND ONLY** development phase.
- Technologies: HTML, CSS, JavaScript (Vanilla, no unnecessary frameworks)
- Data: Centralized Mock Data (`/js/mock-data.js`)
- Backend/DB/Auth: Simulated only. No real API or backend code.

## Project Structure
- `index.html`: Main application entry point
- `pages/`: HTML views for different application screens
- `css/`: Stylesheets and design tokens
- `js/`: Application logic, state management, and mock data
- `assets/`: Images, icons, and media

## Running the Project
Since this is a frontend-only project, you can run it using any simple local HTTP server. For example:
- VS Code Live Server extension
- `npx serve .`
- `python -m http.server`
