# Project Specification

## Product Purpose
An India-focused service-connection platform connecting Clients who need services with Independent/local service providers who offer skills and services. The core brand idea is "Where skills meet opportunity."

## Users
1. **Client**: A person who needs a service.
2. **Provider**: A person who offers a service or skill.

## Features
- Search and discover services, skills, and providers
- Filter by category, location, availability, experience, and pricing
- Submit, review, accept, decline, and manage service requests
- Provider profiles with portfolios, services, pricing, and availability
- Simulated messaging and calling representation
- Two-way review system (Client -> Provider, Provider -> Client)

## Categories
- Construction & Labour (General Labour, Mason, Painter, Carpenter, Plumber, Electrician)
- Household Services (Cleaning, Cooking, Domestic Assistance)
- Agriculture (Farm Labour, Harvesting, Field Work)
- Stitching & Clothing (Tailor, Alterations, Stitching)
- Repairs & Maintenance (Appliance Repair, Vehicle / Mechanical Work, Electrical Repair)
- Other

## Functional Requirements
- Responsive Web Application (Desktop, Laptop, Tablet, Mobile)
- Centralized mock data for all dynamic content
- Provider relevance/matching based on skills, location, availability, experience

## Constraints
- FRONTEND ONLY development phase
- No backend, real database, or APIs allowed
- No real authentication, real payments, maps API, or external routing
- HTML, CSS, JavaScript only (No unnecessary frameworks)

## User Flows
Client Flow: Landing -> Choose Client -> Login Sim -> Onboarding -> Dashboard/Discovery -> Search/Category -> Results -> Filters -> Profile -> Request Service -> Confirmation -> Provider Response -> Connection -> Service -> Completion -> Review.
Provider Flow: Landing -> Choose Provider -> Registration -> Profile Setup -> Dashboard -> Incoming Request -> Accept/Decline/Respond -> Connection -> Service -> Completion -> Review Client.
