# Testing Checklist

## General
- [ ] Responsive behavior (Desktop, Laptop, Tablet, Mobile)
- [ ] No horizontal scrolling
- [ ] Accessibility: Semantic HTML, Keyboard navigation, Focus states, Sufficient contrast

## Pages
- [ ] Landing page storytelling and animations
- [ ] Client Onboarding
- [ ] Provider Onboarding
- [ ] Client Dashboard
- [ ] Provider Dashboard
- [ ] Provider Profile View
- [ ] Request Creation and Management

## Navigation & Forms
- [ ] Proper routing/navigation simulated
- [ ] Form validation and error states
- [ ] Empty states handled correctly

## Search & Filtering
- [ ] Search against centralized mock data
- [ ] Partial matches and empty search handling
- [ ] Filters update provider results appropriately
- [ ] Location/radius matching

## Request System
- [ ] Submit a new request
- [ ] Provider receives request
- [ ] Accept/Decline state transitions
- [ ] Cancellation logic
- [ ] Service completion logic

## Edge Cases
- [ ] Zero matching search results
- [ ] Missing required information in forms
- [ ] Invalid routes handling
