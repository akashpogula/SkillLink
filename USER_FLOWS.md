# User Flows

## Client Workflow
1. **Landing Page**: Introduce concept (Where skills meet opportunity)
2. **Choose Client**: "Find a Service" entry point
3. **Login/Registration**: Simulated authentication
4. **Client Onboarding**: Gather basic location/needs
5. **Dashboard / Discovery**: Main hub for finding services
6. **Search / Category Selection**: Find relevant skills
7. **Location Settings**: Define area
8. **Provider Results**: View cards of available providers
9. **Filters**: Narrow down by experience, price, etc.
10. **Provider Profile**: View detailed portfolio and stats
11. **Request Service**: Send service request to provider
12. **Request Confirmation**: Request enters REQUESTED state
13. **Provider Response**: Waits for ACCEPTED/DECLINED/RESPONDED
14. **Connection / Communication**: Simulated chat/call representation
15. **Service**: Execution phase
16. **Completed**: Service is marked complete
17. **Review**: Client leaves rating/review for Provider

## Provider Workflow
1. **Landing Page**: "Offer Your Service" entry point
2. **Choose Provider**: Provider role selection
3. **Registration**: Simulated signup
4. **Profile Creation / Onboarding**: Multi-step guided setup
5. **Services / Skills**: Define offerings
6. **Location & Radius**: Define service area
7. **Experience & Pricing**: Set rates and history
8. **Availability**: Set to Ready/Off Duty
9. **Photos / Portfolio**: Upload work examples
10. **Dashboard**: Manage incoming and active requests
11. **Incoming Request**: Review client request details
12. **Accept / Decline / Respond**: Action on the request
13. **Connection / Communication**: Simulated chat with client
14. **Service**: Execution phase
15. **Completed**: Service is marked complete
16. **Review**: Provider leaves rating/review for Client
